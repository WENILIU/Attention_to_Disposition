## 一、研究背景與動機

### 交易經驗來源
台股「注意→處置」監管事件中，觀察到：
1. 處置期間的利潤比出關跳空更高
2. 進入處置前/第一天下跌，之後反彈
3. 單因子無顯著 alpha，但多因子組合有明顯 alpha
4. 多因子組合太多，怕過度解釋

### 研究目標
- 系統化驗證所有可能的因子
- 找到可重複、有經濟邏輯的 alpha
- 建立完整策略並通過 overfitting 檢測
- 部署到 Paper Trading

## 二、策略最終架構

### 主策略: V20（處置期間做多）

| 項目 | 說明 |
|------|------|
| 邏輯 | 處置限制流動性→賣壓過度→反彈（流動性溢價） |
| 入場 | 處置開始 Day 1（新制）/ Day 4（舊制）收盤買入 |
| 出場 | 處置結束前一天收盤賣出 |
| 濾網 | 流動性>20M, Gap -8%~+4%, 熔斷>400跌停不進, 廣度<40%+MA20下不進 |
| 排除 | 連續5個營業日及沖銷標準（勝率僅51.6%） |
| 績效 | CAGR 114%, Sharpe 5.11, MDD -27.5%, 16/16年 |
| 腳本 | `scripts/v20_daily_signal.py`, `scripts/portfolio_daily.py` |

### 輔助策略: S1 廣度做空

| 項目 | 說明 |
|------|------|
| 邏輯 | 市場廣度暴跌→恐慌過度→短期反轉 |
| 訊號 | 廣度（MA20上股票占比）5日下降>15% |
| 動作 | 做空台指期貨/00649R，持有3天 |
| 績效 | CAGR 15.6%, Sharpe 1.06, 14/16年 |
| 腳本 | `scripts/s1_market_short_signals.py` |

### 確認信號: S4 處置壓力

| 項目 | 說明 |
|------|------|
| 邏輯 | 大量處置進場=市場過熱→做空確認 |
| 訊號 | 當日處置進場≥5檔 + 大盤MA20下 |
| 作用 | 增強S1做空配置（20%→30%），不獨立使用 |
| 腳本 | 整合在 `scripts/portfolio_daily.py` |

### 補充策略: C-Long（注意→處置預測做多）

| 項目 | 說明 |
|------|------|
| 邏輯 | ML預測注意股是否升級處置，買入升級股 |
| 模型 | sklearn GradientBoosting, walk-forward |
| 限制 | 僅大盤MA20上啟用，熊年失效 |
| 績效 | CAGR 73% (6年多頭), 13/18年 |
| 腳本 | `scripts/c_long_production.py` |

### 組合效果

| 配置 | CAGR | Sharpe | MDD | 年正報酬 |
|------|------|--------|-----|----------|
| V20 100% | 114% | 5.11 | -27.5% | 16/16 |
| V20 + Short 30% overlay | 95% | 4.95 | -19.0% | 16/16 |
| V20 70% + Short 20% | 55% | 4.96 | -13.7% | 17/17 |

## 四、關鍵發現（按重要性排序）

1. **處置期間的利潤來自流動性溢價**，不是出關跳空。段1（處置期間）= 全部利潤，段2+3（出關）= 可忽略。

2. **單因子無效，組合有效** — 這是因為 alpha 來自「事件本身」（處置），不是來自預測哪些處置股會漲。所有處置股平均都有正報酬，不需要選股。

3. **市場環境是唯一的過濾維度** — 個股層面的特徵（動量、波動率、融資）都無法區分輸贏。只有大盤廣度和MA20位置有過濾效果。

4. **做空在弱市有效** — 處置首日下跌在弱市更強（+1.03%），強市反而反彈。

5. **新制不改變策略邏輯** — 處置期間更長反而增強流動性溢價效應。

## 五、已測試且拒絕的方向

| 方向 | 拒絕原因 |
|------|----------|
| 個股因子選股（動量/波動/融資/投信） | 無法區分處置股輸贏 |
| 止損濾網 | 降低報酬不降低風險 |
| 乖離率濾網 | 無效果 |
| 處置條件加權配置 | 條件間差異不顯著 |
| C-Short（預測做空） | 不需要預測，機械性做空即可 |
| 個股融券做空 | 74%覆蓋率，5分鐘撮合，不可行 |
| 大盤濾網修復C-Long | 無法解決熊年結構性失敗 |
| 板塊/市值分析 | 無顯著差異 |
| 多因子組合優化 | 過度擬合風險 > 邊際收益 |

## 八、給未來 AI 的指引

1. **不要再加因子**。S3 已證明個股層面沒有可預測的 alpha。
2. **不要改參數**。16/16 年 + 參數不敏感 = 已收斂。
3. **新制數據不足時不要下結論**。至少等 100 筆新制交易。
4. **如果策略失效**，先檢查處置規則是否被交易所修改，再考慮市場結構變化。
5. **容量是主要約束**，不是 alpha。5 檔 × 20% 是上限。
6. **所有測試結果必須推 git**（script + CSV + report）。
