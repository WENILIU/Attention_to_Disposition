## 綜合建議：增強版策略 A

### 訊號優先級規則（當訊號超過持倉上限時）

```
優先順序：
1. 連5日條件 + 大盤（日均成交 > 5億）→ 2x 權重
2. 大盤 + 電子業 → 1.5x 權重
3. 中大盤以上 → 1.0x 權重（正常）
4. 小盤 / 金融 / 營建 → 0.5x 權重
5. 極小盤 + 金融/營建 → 0.3x 或直接跳過
```

### 預期改善

| 改動 | 預期效果 | 風險 |
|------|---------|------|
| 條件加權（連5日 2x） | +0.2~0.5% 年化 | 低（7/7年穩定） |
| 市值偏好（大盤優先） | +1~2% 年化 | 低（8/9年穩定） |
| 板塊迴避（跳過金融/營建） | +0.3~0.5% 年化 | 中（樣本較少） |
| **合計預期** | **+1.5~3% 年化** | 低 |

### 實施注意事項

1. **不要過度擬合**：市值效果是結構性的（大盤股流動性好→處置期間賣壓更容易被吸收），不是統計僥倖
2. **條件加權要保守**：連5日樣本僅 114 筆，雖然穩定但容量有限。用 2x 而非 5x
3. **板塊分類是粗略的**：股票代碼前綴不是精確分類，可能有誤差
4. **新制需重新驗證**：2026-08-10 後規則改變，所有分層需重新校準
