### 邏輯解釋

低波動處置股 = 被處置是因為「規則觸發」而非「劇烈波動」。這類股票：
- 基本面未變，只是觸發了交易限制
- 處置期間的賣壓較小（沒有恐慌拋售）
- 流動性溢價更穩定（機構仍在持有）

高波動處置股 = 因劇烈波動被標記，通常伴隨基本面惡化或不確定性。

## V20 更新建議

### 新增：波動率偏好

```
在訊號超過持倉上限時，優先選低波動股票：
  波動率 = 過去20日日報酬標準差
  排序：低波動優先
```

### 可選：MA60 極端排除

```
排除條件（僅排除極端）：
  若 收盤價 > MA60 × 1.5（乖離 > 50%），跳過
```

### 更新後 V20 規格

```
進場：處置 Day 1 開盤
出場：處置 Day 4 開盤
濾網：
  ✅ 流動性 > 2000萬
  ✅ Gap -8%~+4%
  🆕 波動率排序（低優先）
  🆕 MA60 乖離 > 50% 排除（可選）
風險：無止損，熔斷 >400家
部位：20% 每檔，最多 5 檔
```
