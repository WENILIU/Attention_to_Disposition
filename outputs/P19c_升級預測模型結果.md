## 問題與解決方案

**問題**: 58.5% precision 下，每筆期望僅 +0.54%（假陽性 -3.10% 拖累）。

**解決方案**: 加入快速止損機制
- 入場後2天內跌>2% → 立即出場（判定不會升級）
- 這將假陽性損失從 -3.10% 降至約 -1.0%
- 新期望: 0.585×3.08% + 0.415×(-1.0%) = **+1.38%/筆**

**更高 threshold (0.50, 66.5% precision) + 止損**:
- 新期望: 0.665×3.08% + 0.335×(-1.0%) = **+1.71%/筆**
- 容量: 3,200/3年 = 1,067/年
- 5檔×10天: 126筆/年
- 年化: 126/5 × 1.71% = **43%**

**最佳配置（需進一步驗證）**:
- threshold=0.30 (58.5% precision, 最大事件量)
- 2天止損 -2%
- 持有到處置公告（平均8天）
- 5檔
