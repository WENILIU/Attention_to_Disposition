# P21: C-Long 模型分析與最終結論

## 一、模型特徵重要性（最終版）

### 排名（sklearn GB, 21個特徵）

| 排名 | 特徵 | 重要性 | 解讀 |
|------|------|--------|------|
| 1 | pct_change | 29.4% | 注意原因中的漲幅%（如漲幅達52%） |
| 2 | mom_5d | 12.2% | 近5日股價動量 |
| 3 | text_len | 8.1% | 原因文字長度（嚴重度代理） |
| 4 | hist_disposal_count | 6.6% | 過去一年被處置次數 |
| 5 | bias_20d | 5.6% | 偏離20日均線 |
| 6 | excess_over_threshold | 4.8% | 超過監管門檻的幅度 |
| 7 | turnover | 4.6% | 成交額 |
| 8 | vol_20d | 4.4% | 波動率 |
| 9 | att_count_30d | 4.2% | 30天內被注意次數 |
| 10 | vol_ratio | 3.9% | 量能放大倍數 |

### 模型核心邏輯

前6名 = 66.5% 重要性。模型本質在預測：

> 這隻股票的漲幅/動量是否已經大到明天還會繼續漲到觸發處置？

- 漲幅50%+ = 超過第一款門檻(35%) = 明天大概率繼續被注意 = 升級處置
- 近5日強動量 = 趨勢延續 = 明天繼續漲
- 之前被處置過 = 這隻股票體質容易被處置
- 偏離均線越多 = 越極端 = 越可能被監管介入

## 二、模型改善測試結果

### 測試了什麼

| 方案 | 描述 | AUC | CAGR | Sharpe | 結論 |
|------|------|-----|------|--------|------|
| A: 原始 + sklearn GB | 基準（p20b 配置） | 0.8334 | 70.2% | 2.00 | 最佳 |
| B: 原始 + LightGBM | 換模型算法 | 0.8342 | 28.1% | 0.98 | 較差 |
| C: 增強文字 + LightGBM | 加門檻距離等特徵 | 0.8342 | 28.1% | 0.98 | 無提升 |
| D: 加 consecutive_days | 連續天數作為輸入 | 0.8335 | 57.8% | 1.66 | 較差 |

### 為什麼 LightGBM 較差？

AUC 相同（0.834）但 CAGR 差很多。原因：
- LightGBM 的概率校準不同，threshold=0.55 對 LightGBM 來說太鬆
- sklearn GB 的概率分佈更集中，0.55 是好的切分點
- 這是模型 calibration 問題，不是預測能力問題

### 為什麼新特徵沒用？

| 新特徵 | 重要性 | 原因 |
|--------|--------|------|
| consecutive_days | 2.05% | 已被 att_count_30d + days_since_last_att 覆蓋 |
| sector_attention_5d | 2.22% | 板塊聚集已被 hist_disposal_count 間接捕捉 |
| repeat_remaining | ~0% | 文字解析不準確 |
| stated_days_window | ~0% | 與 kuai 高度共線 |

## 三、最終結論：模型已達天花板

### 當前性能（誠實數字）

配置：sklearn GB + 原始特徵 + threshold=0.55 + 連續注意過濾 + 12d smart exit
方法：Walk-forward (2021-2026)

| 指標 | 數值 |
|------|------|
| AUC | 0.833 |
| CAGR | 70-73% |
| Sharpe | 2.00-2.22 |
| MDD | -28% ~ -30% |
| 逐年通過 | 6/6 |
| 平均每筆 | +2.4% |
| 勝率 | 52% |
| 升級精確度 | ~65% |

### 為什麼無法再提升？

1. AUC 0.83 已接近理論上限：注意->處置的升級本質上有隨機性（取決於明天股價）
2. 特徵已窮盡可用資訊：finlab 提供的注意原因文字 + 價格數據已包含所有可獲得的預測資訊
3. 模型算法不是瓶頸：換 LightGBM 不提升 AUC
4. 新特徵冗餘：連續天數、板塊聚集等已被現有特徵隱含捕捉

### 真正的提升方向（非模型）

| 方向 | 可行性 | 預期效果 |
|------|--------|----------|
| 更多新制數據（n>=200後重訓） | 等待中 | 新制 AUC 可能更高 |
| 規則引擎輔助（確定性案例直接判斷） | 可做 | 督導會報=100%升級，跳過模型 |
| 組合優化（C-Long + V20 資金配置） | 可做 | 整體 Sharpe 提升 |
