# P20: C-Long v3 驗證與參數優化

## 目標
驗證 C-Long v3 配置（threshold=0.6, 連續注意, 15d hold）的逐年與新舊制表現，並尋找最佳參數組合。

## 原始 v3 配置驗證結果

### 配置定義
```
訊號：注意公告 + 昨日也被注意(連續) + GB model prob >= 0.6
進場：注意公告次日開盤
出場：處置公告日-1 OR 最多15天
濾網：流動性>20M, Gap -8%~+4%
止損：無
部位：5檔，每檔20%
```

### Event-level 結果（無部位限制）

| 年份 | n | 平均報酬 | 勝率 | 精確度 | 判定 |
|------|---|----------|------|--------|------|
| 2021 | 404 | +1.45% | 44.3% | 58.9% | PASS |
| 2022 | 131 | -0.80% | 39.7% | 60.3% | FAIL |
| 2023 | 249 | +1.06% | 45.8% | 69.9% | PASS |
| 2024 | 469 | +1.21% | 49.7% | 65.2% | PASS |
| 2025 | 401 | +1.80% | 51.9% | 68.3% | PASS |
| 2026 | 979 | +3.17% | 52.1% | 68.7% | PASS |

**逐年通過: 5/6**

### Portfolio-level 結果（5檔限制）

| 指標 | v3 (0.6+consec+15d) | v2 (0.5+10d) |
|------|---------------------|--------------|
| CAGR | 29.4% | 57.7% |
| Sharpe | 1.07 | 1.68 |
| MDD | -45.9% | -39.2% |
| Avg return | +1.42% | +1.83% |
| Win rate | 47.9% | 49.7% |
| 逐年通過 | 3/6 | — |

**結論：v3 配置在組合層面表現較差。原因：**
1. 連續注意過濾 + 高門檻 → 訊號太少 → 複利效果差
2. 15d 最長持有 → 資金效率低
3. 雖然單筆品質高（precision 66%），但數量不足以填滿部位

## 參數掃描結果

### 掃描網格
- Threshold: 0.40, 0.50, 0.55, 0.60
- Consecutive: YES / NO
- Max Hold: 7d, 10d, 12d, 15d
- 出場邏輯：處置公告日-1 OR max_hold（取較早者）

### TOP 5 by Sharpe（要求 5+ 年通過）

| 排名 | Threshold | Consec | Hold | CAGR | Sharpe | MDD | 逐年 |
|------|-----------|--------|------|------|--------|-----|------|
| 1 | 0.55 | YES | 12d | 73.3% | **2.22** | -30.4% | 6/6 |
| 2 | 0.60 | YES | 12d | 68.0% | 2.17 | -33.6% | 6/6 |
| 3 | 0.55 | NO | 12d | **83.3%** | 2.10 | -34.7% | 6/6 |
| 4 | 0.60 | NO | 12d | 73.3% | 2.02 | -31.1% | 6/6 |
| 5 | 0.50 | YES | 12d | 65.6% | 2.00 | -36.4% | 6/6 |

### TOP 5 by CAGR（要求 5+ 年通過）

| 排名 | Threshold | Consec | Hold | CAGR | Sharpe | MDD | 逐年 |
|------|-----------|--------|------|------|--------|-----|------|
| 1 | 0.55 | NO | 12d | **83.3%** | 2.10 | -34.7% | 6/6 |
| 2 | 0.50 | NO | 12d | 76.5% | 2.00 | -36.5% | 6/6 |
| 3 | 0.60 | NO | 12d | 73.3% | 2.02 | -31.1% | 6/6 |
| 4 | 0.55 | YES | 12d | 73.3% | 2.22 | -30.4% | 6/6 |
| 5 | 0.60 | YES | 12d | 68.0% | 2.17 | -33.6% | 6/6 |

### 關鍵發現

1. **12d 是最優 max_hold**：不是 10d（太短，錯過部分處置），不是 15d（資金效率差）
2. **Threshold 0.55 是甜蜜點**：0.5 太鬆（MDD 大），0.6 太緊（訊號少）
3. **連續注意過濾提升 Sharpe**（2.22 vs 2.10）但降低 CAGR（73% vs 83%）
4. **所有 6/6 年配置都用 12d hold**：這是穩健的結構性發現

## 最終推薦配置：C-Long v3.1

### 保守版（最大 Sharpe）
```
訊號：注意公告 + 昨日也被注意(連續) + GB model prob >= 0.55
進場：注意公告次日開盤
出場：處置公告日-1 OR 最多12天（取較早者）
濾網：流動性>20M, Gap -8%~+4%
止損：無
部位：5檔，每檔20%
```

| 指標 | 數值 |
|------|------|
| CAGR | 73.3% |
| Sharpe | 2.22 |
| MDD | -30.4% |
| 逐年通過 | 6/6 |
| 平均持有 | ~10 天 |
| 交易筆數 | 631 (walk-forward) |

### 積極版（最大 CAGR）
```
同上，但移除「連續注意」條件
```

| 指標 | 數值 |
|------|------|
| CAGR | 83.3% |
| Sharpe | 2.10 |
| MDD | -34.7% |
| 逐年通過 | 6/6 |

### 建議
使用**保守版**（含連續注意），原因：
- Sharpe 更高（2.22 vs 2.10）
- MDD 更低（-30.4% vs -34.7%）
- 實盤執行更簡單（只做連續注意 = 訊號更少更精準）
- CAGR 差距不大（73% vs 83%），但風險調整後更優

## 新制 vs 舊制

| 指標 | 舊制 (2021-2026/8) | 新制 (2026/8+) |
|------|---------------------|----------------|
| 升級率 | 66.1% | 68.3% |
| 平均報酬 | +1.80% | +3.93% |
| 勝率 | 48.6% | 57.0% |

**新制表現更好**，不需要調整參數。原因：
- 新制處置期間縮短 → 升級更確定 → 模型更準確
- 新制注意事件升級率更高（37.2% vs 26.5%）

## 實盤腳本使用方式

```bash
# 訓練模型（首次或定期更新）
python scripts/c_long_production.py --train

# 每日執行（生成今日訂單）
python scripts/c_long_production.py

# 完整回測驗證
python scripts/c_long_production.py --backtest
```

輸出：
- `c_long_output/orders_today.csv` — 今日買賣指令
- `c_long_output/portfolio_state.json` — 目前持倉狀態
- `c_long_output/c_long_model.pkl` — 訓練好的模型
