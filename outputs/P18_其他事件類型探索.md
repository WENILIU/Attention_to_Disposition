# P18: 其他事件類型探索報告

## 研究目的

尋找與處置策略機制類似的其他事件，擴展 alpha 來源。

## 測試的事件類型

### 1. trading_halt (停損/停利 — 漲跌停暫停交易)

| 項目 | 結果 |
|------|------|
| 資料來源 | finlab trading_halt |
| 總事件數 | 14,599 (含權證/ETF/興櫃) |
| 股票事件(2018+) | 537 |
| 通過流動性濾網 | **1** |
| 判定 | **不可行** |

**原因**: 漲跌停(±7%)對流動性好的股票極少觸發。大盤股單日跌7%是極端事件，不是可重複的模式。

### 2. margin_short_sale_suspension (停券 — 融券放空暫停)

| 項目 | 結果 |
|------|------|
| 資料來源 | finlab margin_short_sale_suspension |
| 總事件數 | 39,305 |
| 股票事件(2018+, 非除息) | 15,384 |
| 通過V20濾網 | 7,053 |
| 1d報酬 | **-1.38%** (win 22.6%) *** |
| 3d報酬 | -0.78% (win 37.4%) *** |
| 判定 | **方向相反，非同一機制** |

**關鍵發現**:
- 停券原因 87% 是「股東常會」(13,488筆)，不是波動率事件
- 報酬為**負向**（做空訊號），不是做多
- 機制：停券前空頭回補推升股價 → 停券後失去支撐 → 回落
- 這是 short-covering reversal，不是 forced-selling bounce
- 與處置的機制完全不同

**逐年穩定性**: 8/9年負報酬（2020例外+1.23%）。作為做空策略穩定，但：
- 需要融券成本（已證明吃掉alpha）
- 股東常會是可預測事件（非突發），市場已price in

### 3. day_trade_short_suspension (當沖放空暫停)

| 項目 | 結果 |
|------|------|
| 原因分佈 | 股東常會 15,111 / 除息 12,267 / 分配收益 4,463 |
| 判定 | **不相關** — 全部是公司治理/除息事件 |

### 4. important_info_announcement (重大訊息公告)

| 項目 | 結果 |
|------|------|
| 總事件數 | 1,257,774 |
| 資料格式 | 非結構化文字 (title + info) |
| 判定 | **需NLP處理，非短期可完成** |

內容範例：人事異動、增資、投資、董事會決議等。需要：
1. 分類引擎（哪些是市場敏感的）
2. 事件時間戳對齊
3. 大量NLP工作

### 5. esb_attention_disposal (VIP增強版注意/處置)

與現有 trading_attention + disposal_information 相同資料，只是VIP版有更多欄位。不增加新資訊。

## 總結

| 事件類型 | 可行性 | 原因 |
|----------|--------|------|
| 停損/停利 (trading_halt) | ❌ | 流動性股票幾乎不觸發 |
| 停券 (short suspension) | ❌ | 方向相反(做空)，機制不同，主因是股東會 |
| 當沖放空暫停 | ❌ | 同上，全是除息/股東會 |
| 重大訊息 | ⚠️ | 需NLP，非短期項目 |
| 其他監管事件 | ❌ | finlab無其他相關資料 |

## 核心結論

**處置事件在臺灣市場是獨一無二的。** 它結合了：
1. 高頻率（2,255筆/8年，流動性股票）
2. 清晰機制（強制平倉 → 超賣 → 反彈）
3. 多日持續（允許系統性進出場）
4. 結構化資料（容易回測）

沒有其他事件同時具備這些條件。

## 真正的下一步方向

既然事件擴展不可行，提升策略的方向是：

| 方向 | 類型 | 預期效果 |
|------|------|----------|
| 新制樣本累積 | 驗證 | 確認策略在新制下持續有效 |
| 執行優化 | 微觀 | 降低滑價，提升1-2% |
| 資金效率 | 組合 | 多策略並行（如處置+其他非相關策略） |
| 重大訊息NLP | 新alpha | 長期項目，需數月開發 |
| 跨市場 | 擴展 | 日本/韓國類似機制（需新資料源） |
