## 1. 研究架構總覽

### 1.1 核心問題

本研究要回答的不是「哪個因子能預測出關後報酬」，而是：

> 在注意公告的當下，憑當時已知資訊，能否預測升級、能否交易、能否在處置期間或注意→處置段赚到成本後利潤？

### 1.2 故事鏈與時間軸

```
起漲(M1) → 注意公告(M0) → 處置公告 → 處置生效/關中(M2) → 出關 → 出關後
              ↑                    ↑              ↑                              ↑
         研究重點①            研究重點②    研究重點③                    對照組
         O2: 關前交易         O3: 公告→生效  O4: 處置期間分段         O5: 出關後
         O1: 升級預測
```

**研究優先級**：O2 > O4 > O3 > O1 >> O5

O5（出關後）保留作對照，不再佔主要研究量。

## 2. 核心設計原則（全程適用）

1. **母體完整性**：所有事件留在分母。未升級的注意股、沒走完劇本的起漲股都要保留。
2. **as-of 紀律**：每個因子只用決策時點已知的資訊。注意名單盤後公布，最早次一交易日進場。
3. **先寫假說再看結果**：預先登記假說與通過標準，不掃描參數挑最佳值。
4. **結論分級**：資料不足 / 淘汰 / 探索性 / 候選 / 穩健候選 / 策略級通過。未經逐筆交易模擬不得稱為「已驗證策略」。
5. **邊際貢獻優先**：不要求因子單獨顯著，只要求加入後組合有統計顯著的邊際改善。
6. **可交易性強制**：所有 O2/O3/O4 結果必須分三層報告（全樣本 / 可成交 / 無法成交）。
7. **搜索空間控制**：因子組合方法預先指定，不做事後搜索。

### 禁用措辭

- 「偏相關衰減 = 中介效應」
- 「平均與中位數分歧 = 統計假象」
- 「分點流向 = 已證明主力」
- 「搜尋量 = 情緒方向」
- 「升級機率高 = 做多訊號」（方向由 O2 結果決定，不由 O1 推論）

## 3. 結果變數定義

### O1：升級機率（輔助指標，非交易指標）

| 項目 | 定義 |
|------|------|
| 定義 | 注意公告後 k 日（k=5/10/20）內進處置的機率 |
| 母體 | 全部注意事件（含未升級者） |
| 指標 | PR-AUC、校準曲線、Brier Score。不用準確率（類別不平衡） |
| 用途 | 篩選因子是否携带升級預測資訊，作為 O2 的前置條件 |
| 注意 | O1 顯著不代表可交易。高升級率可能意味著一字漲停買不到 |

### O2：注意→處置段報酬（主要研究量 ①）

| 項目 | 定義 |
|------|------|
| 定義 | 全部注意事件，公告次日起 1/3/5/10 日報酬與市場調整報酬 |
| 母體 | 全部注意事件（含未升級者）。不能只挑後來進處置的 |
| 進場 | 公告次一交易日開盤與收盤兩套代理 |
| 出場 | 固定持有日；或處置公告後、正式生效前退出（需確認公告時間） |
| 指標 | 原始報酬、市場調整報酬、勝率、中位數、最大不利變動、成本後報酬 |
| **可交易性分層** | **必須分三層報告（見下方）** |
| 成本 | 手續費 0.1425%、證交稅 0.3%、另加滑價敏感度 |

**O2 可交易性三層報告（強制）**：

| 層級 | 定義 | 用途 |
|------|------|------|
| 全樣本 | 所有注意事件，含一字漲停/跌停 | 描述性，不可交易，僅供理解 alpha 來源 |
| 可成交 | 排除一字漲停/跌停、次日成交量 < 門檻的事件 | 這是唯一可用的策略績效 |
| 無法成交 | 被排除的事件 | 分析其特征：如果 alpha 全在這裡，因子實務上無用 |

### O3：處置公告→生效日報酬

| 項目 | 定義 |
|------|------|
| 定義 | 已升級事件：處置公告日到生效日的報酬 |
| 前置 | 需確認處置公告時間欄位；無法確認則標「無法驗證」 |
| 用途 | 理解公告→生效段的風險與報酬 |

### O4：處置期間報酬（主要研究量 ②）

| 項目 | 定義 |
|------|------|
| 定義 | 已進處置事件，分段報酬 |
| 分段 | 買入→關中某日 / 關中末日→出關開盤 / 出關開盤→收盤 |
| 母體 | 已進處置事件；每個交易日重新建立當日仍可進場的風險集合 |
| 進場規則 | 固定日進場（第1/2/3日）/ 跌深後承接 / 強勢延續（三種預先指定，不事後挑） |
| 指標 | 各段淨報酬、勝率、尾部虧損、成本後報酬 |
| **可交易性** | 處置期間成交受限，必須標記無法成交事件 |
| 新舊制 | 2026-08-10 新制樣本短，僅作監測，不與舊制混合結論 |

### O5：出關後報酬（對照組）

| 項目 | 定義 |
|------|------|
| 定義 | 出關後 5/10/20 日報酬 |
| 用途 | 僅作對照，不再佔主要研究量 |
| 注意 | 既有 F 系列結果保留，但不作為新因子的主要測試目標 |

#### P3：核心因子測試

**目標**：測試核心因子對 O1 的增量預測力，以及對 O2 的初步信號。

**測試因子**：A4, A5, A6, A10, A11, B4, B5, B6（8 個因子）
**控制變數**：A3 規則狀態 + A1 條款類型 + S1-S4 分層

**每個因子的測試流程**：

```
Step 1: 描述性檢驗
  - 因子與 O1 的 Spearman 相關（連續）或分組升級率（分組）
  - 因子與 O2 的 Spearman 相關或分組報酬
  - 分層報告（S1-S4）

Step 2: 增量檢驗（邊際貢獻）
  - 基準模型：A3 + A1 + 市場控制
  - 加入因子 X：
    (a) 對 O1：ΔAUC + bootstrap 95% CI（CI 不含 0 → 通過）
    (b) 對 O2：回歸係數 t-stat（cluster SE by stock × date）
    (c) 對 O2：組合 IC/ICIR 變化（bootstrap 95% CI 是否包含 0）
  - 判定：(a) 或 (b) 或 (c) 任一通過 BH 校正 q≤0.10 → 保留

Step 3: 穩定性檢驗
  - 前後半段期間方向一致
  - 不同條款類型方向一致（至少上漲型與下跌型不矛盾）
  - 扣除成本後 O2 報酬仍為正

Step 4: 結論分級
  - 通過全部標準 → 候選
  - 顯著但未通過全部 → 探索性
  - 方向相反或無一致證據 → 淘汰
  - 樣本不足 → 資料不足
```

**通過標準（預設，不可事後放寬）**：
1. 每組至少 30 個獨立事件
2. 平均與中位數同號
3. 全因子家族 BH 校正 q ≤ 0.10
4. 前後半段方向一致
5. 扣除成本後為正（O2）
6. 對 A3 基準有增量（ΔAUC ≥ 0.03 或 IC 變化 CI 不含 0）
7. 標準誤：依股票與日期聚類（cluster bootstrap）

**前置**：P2 + 通過閘門 G1。

#### P4：O2 可交易性驗證

**目標**：把 P3 通過的因子接到可交易報酬，強制三層報告。

**工作項目**：

| # | 項目 | 具體內容 |
|---|------|---------|
| 4.1 | 全樣本報酬 | 全部注意事件，按因子分組的 1/3/5/10 日原始報酬與市場調整報酬 |
| 4.2 | 可成交子樣本 | 排除一字漲停/跌停、成交量 < 門檻的事件，重新計算 |
| 4.3 | 無法成交特徵 | 分析被排除事件的特徵：如果 alpha 集中在這裡，因子實務上無用 |
| 4.4 | 成本後報酬 | 手續費 0.1425% + 證交稅 0.3% + 滑價敏感度（0.5%/1%） |
| 4.5 | 尾部風險 | 最大不利變動、5% 分位報酬、虧損超過成本的頻率 |
| 4.6 | 長短邏輯分離 | 高強度上漲型 ≠ 做多訊號。低強度灰區可能有「落空」交易路徑 |

**關鍵原則**：
- 「事後確實進處置者的平均報酬」是路徑描述，不是策略績效
- 升級方向不能從 O1 推論交易方向，必須由 O2 結果決定
- 如果可成交子樣本的 alpha 消失 → 因子標記「實務不可交易」

#### P5：O4 處置期間分段分析

**目標**：回答「處置期間能不能賺錢、錢在哪一段賺到」。

**三種預先指定的進場規則（不事後挑最佳）**：

| 規則 | 決策當時能知道什麼 | 出場選項 |
|------|------------------|---------|
| 固定日進場 | 處置第 1/2/3 個交易日及當時制度 | 處置結束日前 / 出關日開盤 / 出關日收盤 |
| 跌深後承接 | 截至前一交易日的回檔、量縮、波動 | 固定持有日 / 關前出場 / 出關出場 |
| 強勢延續 | 截至前一交易日的相對強度與價量狀態 | 同上，並與跌深組比較 |

**O4 分段報酬拆解（強制）**：

```
段1: 買入 → 關中某日（處置期間內的利潤）
段2: 關中末日 → 出關開盤（隔夜跳空）
段3: 出關開盤 → 出關收盤（出關日盤中）

必須分段報告，否則不知道錢在哪裡賺到。
「第3天買到出關有利潤」≠「處置期間有利潤」
```

**可交易性**：處置期間成交受限，必須標記無法成交事件。

**新舊制**：2026-08-10 新制樣本短，僅作監測，不與舊制混合結論。

**前置**：P4。

#### P8：因子組合（固定方法，不搜組合）

**目標**：組合通過 P7 的因子，但方法預先指定。

**三種方法（全部執行，取最保守結果）**：

| 方法 | 說明 | 角色 |
|------|------|------|
| IC-weighted | 各因子 IC 的滾動均值作為權重 | 標準方法 |
| Elastic Net | α=0.5, λ 由時間序列 CV 選取 | 自動篩選 + 收縮 |
| 等權重 | 所有通過因子等權 | 對照基準（最保守） |

**不允許**：試了 N 種組合後挑 Sharpe 最高的那個。

**最終判定**：
- 三種方法都通過 P7 標準 → 穩健候選
- 只有 IC-weighted 通過 → 候選（需更多驗證）
- 只有 Elastic Net 通過 → 候選（注意 λ 選擇的穩定性）
- 等權重都不通過 → 不進入策略庫

**前置**：P7。

## 6. 邊際貢獻檢驗方法論（詳細）

這是本規劃的核心方法論，回答「單因子不顯著但組合有效時，因子該不該保留」。

### 6.1 問題定義

傳統做法：對每個因子做單獨回歸，t < 2 就捨棄。
問題：因子之間可能互補（低相關弱信號組合後強），單獨不顯著不代表邊際貢獻為零。

### 6.2 修正方法：增量檢驗

```
對每個候選因子 X：

1. 建立基準模型 M₀：
   - 包含 A3 規則狀態 + A1 條款類型 + 市場控制 + S1-S4 分層
   - 這是「不用 X 時能做到的最好」

2. 加入因子 X，得到模型 M₁

3. 比較 M₁ vs M₀：
   (a) 分類任務（O1）：
       ΔAUC = AUC(M₁) - AUC(M₀)
       Bootstrap 1000 次，95% CI 不含 0 → 通過
   
   (b) 回歸任務（O2/O4）：
       X 的係數 β，cluster SE by stock × date
       t-stat = β / SE(β)
       BH 校正後 q ≤ 0.10 → 通過
   
   (c) 組合 IC：
       IC(M₁) - IC(M₀)
       Bootstrap 95% CI 不含 0 → 通過

4. 判定：
   (a) 或 (b) 或 (c) 任一通過 → 因子保留
   全部不通過 → 因子不進入組合
   注意：不要求因子單獨顯著，只要求邊際貢獻顯著
```

### 6.3 多重檢驗控制

- 全因子家族一起做 BH 校正（q ≤ 0.10）
- 技術形態（P 系列）：整個預先登記的規則宇宙一起做 Reality Check / SPA，不報單一最佳規則的 p 值
- 因子組合（P8）：三種方法預先指定，不增加搜索空間

### 6.4 為什麼這能解決「多因子組合過度解釋」

- 因子數量從 57 縮到 15+10，搜索空間大幅縮小
- 每個因子必須證明邊際貢獻，不是單獨顯著
- 組合方法固定，不搜組合
- 閘門機制確保只有通過前序檢驗的因子才進入後續階段
- 樣本外只跑一次（2023 年以後）

## 9. 每個測試項目的具體操作說明

### 9.1 A3：規則狀態機

**做什麼**：從注意交易資訊文字判斷每檔股票在每個交易日處於哪個規則狀態。

**為什麼是基準**：處置公告的第一層幾乎完全由注意計數狀態決定（已驗證）。所有其他因子必須在 A3 之上提供增量。

**怎麼測**：
- 輸入：trading_attention 的注意交易資訊文字
- 處理：規則狀態機（武裝/未武裝/已觸發），含各條款類型
- 輸出：每個股票×交易日的狀態標籤
- 驗證：與 disposal_information 對照，確認狀態機能否重現處置觸發

**通過標準**：處置觸發的召回率 ≥ 95%（規則狀態是確定性的，應該接近 100%）。

### 9.2 A4：文字強度

**做什麼**：從注意公告文字直接讀取六日累積漲跌幅，作為升級強度的代理。

**為什麼重要**：初步結果顯示完全單調的升級率梯度（36.8% → 91.1%），且在 2023 年以後樣本外驗證通過。

**怎麼測**：
- 輸入：注意交易資訊文字中直接揭露的數字
- 處理：解析漲幅/跌幅百分比，按方向分組
- 輸出：每個注意事件的文字強度值
- 對 O1：五分位升級率 + ΔAUC
- 對 O2：五分位成本後報酬 + 三層可交易性報告

**注意**：
- 不用日線收盤價反推（已淘汰，吻合率 < 0.5%）
- 下跌型樣本不足（11-20 筆），暫列探索性
- 升級機率高 ≠ 做多訊號，方向由 O2 決定

### 9.3 A5：價量動量

**做什麼**：計算注意公告日盤後可得的近 5/10/20 日價格動量與量能變化。

**為什麼**：A4 已證明價量特徵對升級預測有增量（ΔAUC = +0.0984）。需要正式化。

**怎麼測**：
- 輸入：日 K 價量（adj_close, volume）
- 處理：5/10/20 日報酬、成交量變化率、量價背離指標
- 輸出：每個注意事件的價量特徵
- 對 O1：增量 AUC（在 A3+A4 之上）
- 對 O2：分組報酬 + 邊際貢獻

### 9.4 A6：波動率與週轉率

**做什麼**：計算近 20 日波動率、週轉率水平與變化。

**為什麼**：高波動/高週轉代表關注度高，可能影響可成交性和風險。

**怎麼測**：
- 輸入：日 K 價量
- 處理：20 日已實現波動率、週轉率均值與變化
- 輸出：每個注意事件的波動/週轉狀態
- 對 O2：作為風險控制變數或交互項

### 9.5 A10：三大法人

**做什麼**：計算注意公告日前 5 日的外資/投信/自營累計買賣超。

**為什麼**：機構行為可能反映知情交易。

**前置**：P0 確認資料鍵名和欄位。

**怎麼測**：
- 對 O2：在 A3+A4+A5+A6 之上的邊際貢獻
- 分層：外資買入 vs 賣出 vs 中性

### 9.6 A11：融資融券

**做什麼**：融資餘額變化、融資/現股比。

**為什麼**：融資代表散戶槓桿情緒，可能預測短期反轉或延續。

**怎麼測**：同 A10，在核心因子之上的邊際貢獻。

### 9.7 B4-B6：分點集中度與方向

**做什麼**：從分點 CSV 計算前 5 大分點的買賣占比、淨買入方向、5 日變化。

**為什麼**：處置期間的主力行為可能影響段內報酬。

**注意**：分點不等於投資人；主力成本為近似。

**怎麼測**：
- 主要對 O4：在處置期間不同進場規則下，分點狀態是否預測段內報酬
- 對 O2：邊際貢獻較弱，作為次要測試

### 9.8 O2 可交易性驗證（P4）

**做什麼**：把 P3 通過的因子接到實際交易模擬。

**三層報告**：

```
層 1 — 全樣本（描述性）：
  所有注意事件，按因子分組的 1/3/5/10 日報酬
  用途：理解 alpha 來源和大小

層 2 — 可成交子樣本（策略績效）：
  排除：一字漲停（買不到）、一字跌停（賣不掉）、成交量 < 門檻
  用途：這是唯一可用的策略績效
  指標：成本後淨報酬、勝率、Sharpe、尾部虧損

層 3 — 無法成交子樣本（診斷）：
  被排除的事件
  用途：如果 alpha 全在這裡 → 因子實務上無用
  分析：這些事件的共同特徵是什麼？
```

### 9.9 O4 處置期間分析（P5）

**做什麼**：回答「處置期間能不能賺錢、錢在哪一段賺到」。

**三種規則的測試邏輯**：

```
規則 1 — 固定日進場：
  進場：處置第 1/2/3 個交易日開盤
  出場：處置結束日前 / 出關開盤 / 出關收盤
  比較：哪個進場日 × 哪個出場 = 最佳？（但這是描述，不是策略）
  策略：預先指定「第 3 天進、出關開盤出」作為基準（你的交易經驗）

規則 2 — 跌深後承接：
  進場條件：截至前一交易日已跌 X%（X 預先指定）
  出場：同規則 1
  比較：與規則 1 的基準比較

規則 3 — 強勢延續：
  進場條件：截至前一交易日相對強度 > Y%
  出場：同規則 1
  比較：與規則 2 比較（互斥邏輯）

所有規則都必須：
  - 分段報告 O4（段1/段2/段3）
  - 標記無法成交
  - 扣除成本
  - 新舊制分開
```

### 9.10 P7 策略級模擬

**做什麼**：對通過 P3-P6 的因子做逐筆交易模擬。

**模擬規則**：
- 不用因子分數連續權重，用預先指定的規則（如「A4 高強度 + A6 低波動 → 買入」）
- 固定進出場時點
- 無法成交標記，不刪除
- 開發期 2022 年以前，測試期 2023 年以後
- 新制僅監測

**輸出**：
- 逐筆交易表（chain_trade_sim_*.csv）
- 成本後績效
- 尾部虧損分布
- 資金效率（年化報酬 / 平均持有天數）

### 9.11 P8 因子組合

**做什麼**：組合通過 P7 的因子。

**方法（預先指定，不搜組合）**：

```
方法 A — IC-weighted：
  權重 = 各因子 IC 的滾動均值（窗口預先指定）
  每期末更新權重

方法 B — Elastic Net：
  α = 0.5（固定）
  λ 由時間序列交叉驗證選取
  自動將邊際貢獻小的因子權重壓到零

方法 C — 等權重：
  所有通過因子等權
  作為最保守對照

最終判定取最保守結果（通常是等權重）。
```

## 11. 風險與限制

| 風險 | 影響 | 緩解 |
|------|------|------|
| 注意股次日一字漲停比例高 | O2 可成交樣本可能極少 | 三層報告強制；如果可成交 alpha 消失，誠實結論 |

| 注意事件與題材重疊 | 事件不獨立 | cluster SE by stock × date |
| 因子數量仍然較多 | 多重檢驗風險 | BH 校正 + 閘門 + 固定組合方法 |
