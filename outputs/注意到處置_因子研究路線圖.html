P3 每個因子的測試流程

Step 1: 描述性檢驗

  • Spearman 相關 / 分組升級率 / 分組報酬
  • 分層報告（S1-S4）

Step 2: 增量檢驗（邊際貢獻）

  • 基準模型 M₀ = A3 + A1 + 市場控制
  • 加入因子 X → M₁
  • (a) ΔAUC + bootstrap 95% CI
  • (b) 回歸係數 t-stat（cluster SE）
  • (c) IC/ICIR 變化 + bootstrap CI
  • 任一通過 BH 校正 q≤0.10 → 保留

Step 3: 穩定性檢驗

  • 前後半段方向一致
  • 不同條款類型方向一致
  • 成本後 O2 報酬仍為正

Step 4: 結論分級

  • 通過全部 → 候選 | 部分 → 探索性 | 反向 → 淘汰 | 樣本不足 → 資料不足

P4 三層報告（強制）

層級定義用途

關鍵原則

  • 「事後進處置者的報酬」是路徑描述，不是策略績效
  • 升級方向不能從 O1 推論交易方向
  • 可成交 alpha 消失 → 標記「實務不可交易」

邊際貢獻檢驗流程

核心問題：單因子不顯著但組合有效時，因子該不該保留？
答案：不看單獨顯著性，看加入後組合是否有統計顯著的邊際改善。

基準模型 M₀
A3 + A1 + 市場控制
+ S1-S4 分層
→
加入因子 X
得到模型 M₁
→
比較 M₁ vs M₀
(a) ΔAUC + CI
(b) 係數 t-stat
(c) IC 變化 + CI
→
BH 校正
全因子家族
q ≤ 0.10
→
任一通過 → 保留
全部不通過 → 不進入組合

層級方法適用範圍

O2 可交易性三層報告

層級定義用途
全樣本所有注意事件，含一字漲停/跌停描述性，理解 alpha 來源和大小
可成交排除一字漲停/跌停、成交量 < 門檻唯一可用的策略績效
無法成交被排除的事件如果 alpha 全在這裡 → 因子實務上無用

⚠ 如果高強度注意股 90% 隔日一字漲停，可成交子樣本的 alpha 可能為零。這必須誠實報告。

+
