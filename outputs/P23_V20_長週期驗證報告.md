### 為什麼 V20 能穿越牛熊？

**核心邏輯差異：**

| | V20 (處置期間做多) | C-Long (注意→處置做多) |
|---|---|---|
| 交易對象 | 已被處置的股票 | 預測將被處置的股票 |
| 獲利來源 | 流動性溢價(被強制賣出後的反彈) | 升級預期(處置公告的利好) |
| 市場依賴 | 不依賴方向(事件驅動) | 依賴上漲(需要繼續漲才升級) |
| 本質 | 提供流動性給強制賣方 | 投機性預測 |

V20 的 alpha 來源是**結構性的**：
1. 處置期間有強制賣壓(融資強平、散戶恐慌)
2. 流動性提供者(買入者)獲得溢價
3. 這個機制不管牛熊都存在

## 策略定位（最終版）

| 策略 | 定位 | 角色 |
|------|------|------|
| **V20** | 主策略 | 核心收益來源，穿越週期 |
| C-Long | 輔助策略 | 多頭時增強收益，空頭時可關閉 |
| C-Short | 已放棄 | 融券成本吃掉所有alpha |

### 實盤建議

| 環境 | 操作 |
|------|------|
| 正常/多頭 | V20 + C-Long 同時運行 |
| 空頭(大盤跌>5%) | 只運行 V20，關閉 C-Long |
| 極端恐慌(熔斷) | 全部暫停9天 |

## 注意事項

1. 2011-2013 樣本極少(n=5,7,20)，統計意義有限
2. 2014年後(n>=56)結果才有統計效力
3. 2014-2026 = 13/13 年正，這是可信的
4. 早期處置規則可能與現在不同(需確認)
5. 流動性濾網(<20M)排除了很多早期小盤股
