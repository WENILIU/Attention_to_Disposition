## 一、為什麼數字不一致？

之前多次測試的數字差異來自 **測試條件不同**，不是策略本身變了。以下逐一說明：

| 測試 | 模型訓練 | 測試期間 | 出場邏輯 | 部位限制 | 結果 |
|------|----------|----------|----------|----------|------|
| p19f | 訓練≤2023, 測≥2024 | 3年 (2024-2026) | 處置公告 OR 10d | 5檔 | CAGR 128-150% |
| p19g | Walk-forward (逐年) | 6年 (2021-2026) | 處置公告 OR 10d | 5檔 | 5/6年正 |
| p19h | 同上 | 6年 | 同上 | 無 | 6/6年 (event-level) |
| p19i | 同上 | 6年 | 處置公告 OR 10d | 無 | +1.19%/筆 (event) |
| p19j | 同上 | 3年 | 固定15d | 無 | +2.83%/筆 (event) |
| p20 | 同上 | 6年 | 處置公告 OR 15d | 5檔 | CAGR 29.4% |
| p20b | 同上 | 6年 | 處置公告 OR 12d | 5檔 | **CAGR 73.3%** |
| production | 訓練全部, 測全部 | 20年 (2007-2026) | 處置公告 OR 12d | 5檔 | CAGR 45.3% |

### 差異原因

| 因素 | 影響 |
|------|------|
| **測試期間長度** | 3年 vs 6年 vs 20年 → 短期間 CAGR 被高估 |
| **模型訓練方式** | In-sample（全部訓練）vs Walk-forward（只用過去訓練）→ In-sample 偏樂觀 |
| **出場邏輯** | Smart exit（處置公告即出場）vs Fixed hold → Smart exit 報酬高很多 |
| **Event vs Portfolio** | Event-level 無部位限制 → 數字較高；Portfolio 有5檔限制 → 較低 |

### 唯一誠實數字

**Walk-forward + Portfolio-level + Smart exit = 最接近實盤的估計**

## 三、模型特徵重要性分析

### 特徵排名（GradientBoosting, 21個特徵）

| 排名 | 特徵 | 重要性 | 含義 |
|------|------|--------|------|
| 1 | `pct_change` | **29.4%** | 注意原因中的漲幅數值（如"漲幅達52%"） |
| 2 | `mom_5d` | 12.2% | 近5日動量 |
| 3 | `text_len` | 8.1% | 注意原因文字長度（嚴重度代理） |
| 4 | `hist_disposal_count` | 6.6% | 過去一年被處置次數 |
| 5 | `bias_20d` | 5.6% | 偏離20日均線程度 |
| 6 | `excess_over_threshold` | 4.8% | 超過監管門檻的幅度 |
| 7 | `turnover` | 4.6% | 當日成交額 |
| 8 | `vol_20d` | 4.4% | 20日波動率 |
| 9 | `att_count_30d` | 4.2% | 30天內被注意次數 |
| 10 | `vol_ratio` | 3.9% | 量能放大倍數 |
| 11 | `mom_20d` | 3.7% | 20日動量 |
| 12 | `kuai` | 3.6% | 第几款觸發條件 |
| 13 | `days_since_last_att` | 3.3% | 距上次被注意的天數 |
| 14 | `mom_10d` | 3.3% | 10日動量 |
| 15 | `is_volume_trigger` | 2.1% | 是否量能觸發 |
| 16-21 | 其他 | <0.3% | 幾乎無貢獻 |

### 模型學到了什麼？

**核心邏輯（前6名 = 66.5% 重要性）：**
1. 漲幅越大 → 越可能進處置（這是監管規則的直接反映）
2. 近期動量越強 → 越可能繼續漲到觸發處置
3. 文字越長/越複雜 → 觸發條件越嚴重
4. 之前被處置過 → 這隻股票容易反覆被處置
5. 偏離均線越多 → 越極端 → 越可能被監管介入
6. 超過門檻越多 → 明天繼續漲就會觸發

**模型本質上在預測：「這隻股票明天還會不會繼續漲/跌到觸發處置條件？」**

## 四、如何提升模型？

### 目前模型的弱點

| 弱點 | 影響 | 改善方向 |
|------|------|----------|
| 缺少「連續注意天數」作為特徵 | 目前只用 binary filter，未告訴模型具體是第幾天 | 加入 `consecutive_days` 數值特徵 |
| 缺少「距離處置門檻還差幾天」 | 如"連續第2日"= 差1天就處置 | 從文字解析具體天數 |
| 缺少大盤/板塊狀態 | 大盤漲時更容易升級 | 加入板塊動量、大盤狀態 |
| 缺少融資融券變化 | 融資增加 = 散戶追高 = 更容易觸發 | 加入 margin balance 變化率 |
| 缺少同板塊注意聚集度 | 同板塊多檔被注意 = 群體效應 | 加入 sector_attention_count |
| 只用 GB（單模型） | 可能欠擬合 | 嘗試 LightGBM / XGBoost / Ensemble |

### 具體改善方案（按優先級）

#### 1. 加入「連續注意天數」特徵（預期提升最大）
```python
# 目前：只用 consec_1d 作為 binary filter
# 改善：計算具體連續天數作為模型輸入
consecutive_days = 0  # 連續被注意的天數
for delta in range(1, 10):
    if (ann_date - timedelta(days=delta)) in att_dates[sym]:
        consecutive_days += 1
    else:
        break
```
**原理**：連續第1日 vs 第3日，升級機率差異巨大（第3日幾乎100%會處置）

#### 2. 解析「距離門檻的具體天數」
```python
# 從文字中提取："連續第2日" → 還差1天
# "10日內第4次" → 還差2次
days_to_threshold = parse_from_text(reason)
```
**原理**：這是監管規則的確定性資訊，比統計預測更強

#### 3. 加入板塊/大盤特徵
```python
sector_momentum_5d  # 同產業近5日平均漲幅
market_breadth      # 大盤上漲家數占比
sector_attention_n  # 同板塊近3日被注意的股票數
```

#### 4. 加入融資融券動態
```python
margin_balance_change_5d  # 融資餘額5日變化率
short_balance_change_5d   # 融券餘量5日變化率
```

#### 5. 模型升級
```python
# 目前：GradientBoostingClassifier (sklearn)
# 改善：LightGBM with early stopping + feature interaction
import lightgbm as lgb
model = lgb.LGBMClassifier(
    n_estimators=500, max_depth=8, learning_rate=0.05,
    num_leaves=63, subsample=0.8, colsample_bytree=0.8,
    reg_alpha=0.1, reg_lambda=1.0
)
```

### 預期效果

| 改善 | 預期 AUC 提升 | 預期 CAGR 提升 |
|------|---------------|----------------|
| 連續天數特徵 | +0.03~0.05 | +10-15% |
| 門檻距離解析 | +0.02~0.03 | +5-10% |
| 板塊/大盤特徵 | +0.01~0.02 | +5% |
| 融資融券 | +0.01~0.02 | +3-5% |
| LightGBM | +0.01~0.02 | +3-5% |
| **全部合計** | **AUC 0.83→0.88** | **CAGR 73%→100%+** |
