## 三、機制分析

### 公告前的背景

| 時段 | 平均報酬 | 勝率 | 解讀 |
|------|----------|------|------|
| 前 1 天 | +0.30% | 50.7% | 無資訊洩漏 |
| 前 5 天 | -3.17% | 39.0% | 股價下跌中 |
| 前 10 天 | -6.07% | 33.5% | 明顯下跌 |

**公司在股價下跌時宣布買回。** 這是「低買」行為，不是追高。

### Alpha 來源（三重機制）

1. **訊號效應**：管理層認為股價被低估 → 市場跟隨 → Day 1 跳漲
2. **流動性效應**：公司實際進場買入（執行期間 1-3 個月）→ 持續買壓 → 漂移
3. **行為效應**：市場低估了買回的持續影響 → underreaction → drift

### 與 V20 的機制對照

| 維度 | V20 (處置) | P27 (庫藏股) |
|------|-----------|-------------|
| 強制流動性方向 | 賣出（強制平倉） | 買入（公司回購） |
| 觸發條件 | 股價暴漲後 | 股價暴跌後 |
| 機制 | 超賣 → 反彈 | 訊號 + 買壓 → 上漲 |
| 時間結構 | 處置期間（10天） | 公告後持續 30 天 |
| 市場環境 | 全環境有效 | 空頭更好（+10.8% vs +4.4%） |

**這是 V20 的完美鏡像：一個交易強制賣出的反彈，一個交易強制買入的延續。**

## 八、建議策略設計

### 策略代號: B1 (Buyback)

| 項目 | 設計 |
|------|------|
| 邏輯 | 庫藏股公告 = 強制買入 + 低估訊號 → 持續上漲 |
| 入場 | 公告日收盤買入（或次日開盤） |
| 出場 | 持有 20-30 天 |
| 濾網 | 流動性 > 20M |
| 部位 | 5-10 檔，每檔 10-20% |
| 加碼 | 空頭市場可加碼（效果翻倍） |
| 排除 | 無（所有目的、所有規模都有效） |

## 九、風險與限制

| 風險 | 嚴重度 | 說明 |
|------|--------|------|
| 公告時間 | 低 | 庫藏股公告通常在收盤後發布，次日買入仍有效 |
| 容量 | 低 | ~70 筆/年，可分散到 5-10 檔 |
| 選擇偏差 | 低 | 所有規模/目的都有效，非 cherry-pick |
| 過擬合 | 極低 | 17/17 年、p=1e-17、經濟邏輯極強 |
| 執行 | 低 | 一般股票，無特殊交易限制 |
